# Licenses and provenance

`pi-vimux-starship` is private and currently marked `UNLICENSED` as a whole. Imported
third-party-derived components retain their own licenses:

- `pi-vim-LICENSE` covers the imported `pi-vim-top-border` descendant;
- `pi-fancy-footer-LICENSE` covers the imported Fancy Footer fork.

The same license text remains beside each imported source. Local modifications are
recorded in:

- `packages/pi-vim-top-border/LOCAL-CHANGES.md`;
- `packages/pi-fancy-footer-full-palette/LOCAL-CHANGES.md`.

Do not remove or replace these notices when consolidating or packing the source. A
future public release requires an explicit project-level licensing decision in addition
to retaining upstream attribution.
